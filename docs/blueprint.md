# **App Name**: Pop Block Blitz

## Core Features:

- Game Board Generation: Randomly generate a grid of colored blocks for each new game session.
- Block Group Selection & Clearing: Allow players to tap on a group of two or more adjacent, identical blocks to clear them from the board. Remaining blocks fall and columns consolidate.
- Scoring System: Award points based on the number of blocks cleared in a single move, with larger groups yielding higher scores.
- Game Over Condition: Detect when no more valid moves are available and declare the game over, displaying the final score.
- AI Difficulty Adaptation Tool: Utilize AI to curate game board layouts and challenges, dynamically adjusting difficulty based on the player's recent performance.
- High Score Display: Track and display the player's highest score achieved to encourage replayability.

## Style Guidelines:

- Light color scheme, evoking a playful and satisfying feel. Primary interactions use a vibrant aqua (#4DCCE6). The background is a very light, almost white, subtle blue-green (#F3F6F6), and the accent for emphasis or interactive elements is a bright lime green (#C8F471).
- Headlines and body text use 'Poppins', a geometric sans-serif, for a modern, precise, and contemporary look suitable for short bursts of text.
- Game blocks should be simple, distinct shapes (e.g., circles, squares, stars) or color fields, with clear visual separation. Other UI elements should use clean, easily recognizable vector icons.
- A clean, responsive, grid-based layout focused on the game board. Essential UI elements like score and remaining moves are clearly visible at the top, minimizing clutter around the playing area.
- Satisfying block 'pop' animations when groups are cleared, with blocks disappearing and adjacent ones shifting into place with a smooth, fluid motion. Subtle score update animations upon clearing.
